DSRViewer is a program for viewing textures within the Dark Souls 1 archives.

It has some bugs, but if you're interested in examining the game's structure, it lets you do so much faster than the usual method.

It has a built-in injector and file extractor. It can work with multiple windows.

Don't forget to uncheck the "Read-only" attribute on the game folder and grant the program the necessary permissions.

Requires .NET 9.0 to run.
